# 当前天气与免责整句清理补丁

- 删除“这些候选数字对应…调度窗口…”整句，以及非实测/推算/沿用免责句；不再逐词替换成预测值。既有导出的“预测计算结果预测值”“预测计算、预测值”尾部独立免责分句删除，保留前面的储能及拒绝时段事实。接受/排除/非全天范围、门控警告及日志回执边界不删除。
- 当前天气工具默认只取当前记录，回答“当前室外 13.3 °C，湿度 57%”。未来几小时问题才读取未来逐小时记录，每小时单独回答，不合并成多小时共用读数。
- 宿主新增湿度整数显示值 humidity_percent，原始 relative_humidity_pct 及来源保留；提示与来源校验使用整数显示值，不让LLM自行换算或猜测。湿度小数回答/当前天气时段范围触发重写。
- 时间+天气组合答案直接拼接，清除句号后空格；display_time仅作用于当前时钟，不改变天气记录时间、调度或预测。
- experiments/disclaimer_sentence_refresh.json：离线文字清理，正常日21处、高负荷日20处、高拒绝日10处；无新LLM调用或下发，非文字字段不变。
- 真实接口三问各一次，所有结果保留在 experiments/chat_current_weather_results.json：组合时间天气为模板回答，当前天气单问因deadline模板回退，未来逐小时天气为LLM回答。最终均为整数湿度、当前天气无范围、未来天气逐时展开。此批不替代原固定10问，不宣称LLM比例提升。
