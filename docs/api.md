# API and automatic log-dispatch contract

Base URL http://localhost:8000. Product mode auto: confidence gate passes => automatic BA/EMS log dispatch; rejected hours => human work order. Transport is log_only, device_connected=false; no hardware connected.

## GET /health
Preserves status/model_ready, adds llm {mode,reason}. Missing/incomplete LLM config defaults demo, never networks. auto/real with full config may call configured Agnes-compatible endpoint. Credentials/file contents never returned.

## GET /models
Registry exposes legacy champion and demo_model=byron-expanded-holiday-monthly-v1, monthly artifact index. Demo model pooled coverage90.3867% is below target90.5%; automatic product mode does not change measured results. See exports/model_card.json.

## POST /predict
Request {building_id,start,end}: timezone-aware whole-hour one-hour range, latest observed load must be target-1hour. BUILDING_DATA_CSV points to observed history; no future actuals in live prediction. Byron supports2017 historical monthly models. Response keeps building_id,model_version,alpha,predictions; rows contain timestamp,point,lower,upper,confidence,abstain,abstain_reason. Demo confidence is empirical-coverage-backed gate-aligned score, not guaranteed conditional coverage. Missing model/history =>503/422; unknown building404.
