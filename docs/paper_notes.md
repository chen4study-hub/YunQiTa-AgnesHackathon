# 论文核读记录（2026-10-09）

原件：`manuscript_clean.pdf`，20 页；PDF 实际标题为 **Building Energy Forecast Routing for Grid-Responsive BEMS: Selective Conformal Screening under Operational Uncertainty**，并非任务描述中给出的简称。作者 Enhao Cui 等。复现仓库：https://github.com/chen4study-hub/selective-conformal-bems-routing ，存档：https://doi.org/10.5281/zenodo.20396496 。本文件以 PDF 本身为依据，不将论文报告的成绩当作本项目已复现成绩。

## 方法（PDF pp. 4–7）

- 目标：逐建筑逐小时电力用量。1-step 的可用动态信息截至目标时刻 t−1；24 小时提前预测的用量历史截至 t−24。点预测为 LightGBM 预测残差，叠加基准滞后值：1-step 使用 y(t−1)，day-ahead 使用 y(t−24)。输入为消费滞后/滚动统计、日历、气象、建筑元数据；1-step 站点天气仅向前填充并滞后 1 小时，不做后向填充/插值。day-ahead 可部署天气为 WeatherBench2 IFS HRES 历史预报，起报时间 ≤ t−36；缺失处使用 t−24 的观测持久性；目标时刻观测天气仅作 oracle 对照。
- 不是 CQR 主方法：残差尺度模型预测 s>0，非一致性分数 z=|y−ŷ|/s；**自适应尺度的 split conformal**。α=0.095（标称前选择覆盖 90.5%）。按时间顺序 65% 训练、20% 校准、15% 测试；校准段前 65% 训练尺度模型，后 35% (`C_q`) 同时定拒绝阈值和共形乘数；最后测试完全不参与这些操作。
- 训练集的逐建筑、逐用途历史残差均值提供静态风险先验。四分量各自转换为 `C_q` 上的经验百分位，风险分数 g = 0.70 P(s) + 0.15 P(|y(t−1)−y(t−24)|) + 0.10 P(建筑历史风险) + 0.05 P(用途历史风险)。目标拒绝比例 ρ=10%/20%/30%；阈值为 `C_q` 上 g 的 (1−ρ) 分位；g>阈值的测试小时进入 fallback/review。仅在 `C_q` 上 g≤阈值的样本计算归一化残差的第 k 个顺序统计量，k=min(n, ceil((n+1)(1−α)))，区间 `[max(0, ŷ−q*s), ŷ+q*s]`。选择后的覆盖率**只是经验覆盖，不继承标准边际或条件覆盖保证**。论文指出尺度单项/区间宽度门控解释了绝大部分收益；复合分数的 MAE 优势未显著。

## 数据与实验（pp. 6–12）

- BDG2 2016 电力、天气与元数据，排除停车场、要求 ≥95% 完整性和充足滞后信息，16 站点 1,104 栋，9,440,623 小时行；训练 6,134,147、校准 1,888,859、测试 1,417,617 行。HRES 混合变体覆盖 13 站点/995 栋，其余回退。跨站点留出 Bull/Fox/Hog/Lamb/Rat，仅目标站点本地校准。
- GEPIII 标记 2016 年：1–8 月训练、9–10 月校准、11–12 月测试，15 站点 1,230 栋。与 BDG2 大量重叠：0.99 指纹阈值下 731 栋高度匹配；499 栋为“弱匹配”，不等于独立测试。
- 指标：全测试/保留测试 MAE、RMSE、覆盖率、平均区间宽度、实际拒绝率、building-equal 归一化误差/宽度、风险—覆盖曲线、子组覆盖、P99 绝对误差。400 次逐建筑配对 bootstrap（另有周块方法）。CV(RMSE)、NMBE、PINAW 是本项目额外指标，并非此论文表格已给出值。
- 1-step 全测试无拒绝：覆盖 89.55%，宽 21.928，MAE 6.370，RMSE 26.295；30% 目标实际拒绝 27.15%，保留样本覆盖 89.73%，宽 9.363，MAE 2.495，RMSE 5.680（Table 3）。HRES day-ahead 实际拒绝 27.58%，保留覆盖 88.74%（低于 90.5% 标称），宽 18.086，MAE 4.918，RMSE 9.447；不能说自动调度已得到验证。GEPIII 弱匹配 499 栋：实际拒绝 29.99%，保留覆盖 92.01%，MAE 4.011。240 栋诊断样本最差站点仅 77.35% 保留覆盖；站点校准改善但不保证条件覆盖。

## 复现边界

原始 BDG2/GEPIII 未随论文存档再分发；论文仓库提供代码及路径说明。初读时工作区只有 PDF；截至 2026-10-09 原始 BDG2 三文件已齐，并已在六栋子集运行本项目工程版（见 `experiments/bdg2_6building.md`）。小规模可运行管线与 API 不等于原论文 1,104 栋完整复现；任何示例/合成数据指标都不得与上述论文表格并列作实证。论文没有实际空调/储能闭环控制实验；调度只能是保守 demo/影子模式。
