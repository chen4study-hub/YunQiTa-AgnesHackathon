# Unified holiday-expanded monthly demo

Model version byron-expanded-holiday-monthly-v1 is a family of12 deterministic monthly models. Each trains before the preceding28-day calibration window; calibration ends before target month. POST predict/schedule/explain and main replay all resolve the same month bundle. Registry demo_model records user-selected demo separately from legacy other-building champion. Original monthly prediction hashes remain unchanged.

Model card uses pooled Jan-Dec8760hours: retained7344, coverage90.3867%, rejection16.1644%, retainedMAE10.1384, allMAE11.5931. Apr-Dec pooled retained coverage90.4988%, NOT simple month-average90.93%. Exact pooled coverage is below90.5%; do not round it into a pass. Cross-building coverage is null because this new model family has no frozen-source transfer measurement.

Confidence: December2016 out-of-sample warm-up predictions for January; later months accumulate only preceding months' out-of-sample predictions. Risk bins are fixed deciles. Counts/hits/raw empirical coverages are saved, then weighted decreasing isotonic regression stabilizes ranking. No target-month outcomes calibrate its confidence. Empty bins interpolate. Display confidence now blends99% empirical isotonic coverage with1% inverse risk to break plateaus. meta.confidence_threshold uses that same blend at the risk gate. Width-rejected hours receive an explicit below-threshold penalty. Thus rejected iff displayed confidence<threshold, including serialization rounding. This adjusted gate-aligned score is not a pure empirical coverage estimate or probability guarantee; underlying predictions/gate and measured model-card coverage are unchanged.
