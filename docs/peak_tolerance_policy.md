# 峰值容差政策（评测前固定）

用户批准以1 kW或0.1%取较大值消除不可见微差买贵方案。固定政策ID：upper_grid_peak_tolerance_then_cost_v2。

1. 只比较通过约束的既有候选、只计接受预测时段；上界电网峰值和费用保持原全精度。
2. 令p_min为全体候选最小上界峰值，T=max(1 kW,0.001*p_min)。令可接受集合为p<=p_min+T（闭区间，无额外浮点epsilon）。
3. 集合内按原始电费升序，再按上界峰值升序，最后candidate_id，选唯一优胜。缺失电费记+infinity；全部峰值缺失则按原电费/名字安全回退。避免两两相近比较不传递/链式扩张。
4. 同显示费用和峰值成对去重时，保留新政策排序优胜，绝不把新政策全局赢家去掉。轨迹去重仍在。
5. 仅优胜项可执行。非优胜候选摘要明确不选中，不用“多花换峰值”拔高。优胜项若比全局最低电费贵，只有原始峰值收益严格超过T才可陈述多花换峰值；否则只报告容差内比电费，不说买0.0 kW。LLM与聊天若包含违反此口径的多花/付费因果说明，改用宿主摘要；保留选案来源，措辞来源如实template。
