# provider重试（真实评测前固定）

选案和legacy propose：HTTP500或httpx超时异常固定退避0.5秒后重试一次。chat：超时不重试，只对2秒内快速返回的HTTP500退避0.5秒重试一次，且不得超出当前阶段预算。401/403/429/502/校验异常不按本规则重试。结构/grounding原有重写次数另计，transport_attempts记录本地类型/状态/单次耗时，不保存URL、响应正文、异常消息或key。

选案使用原配置timeout。chat总预算30秒，选工具等待10秒、组织回答每次最长18秒且受剩余总预算限制；client单次用满阶段剩余等待（留0.2秒宿主余量），不再压到1.5/2.5秒。超预算返回宿主回答，后台在途结果不再发布；bounded worker最多4，保留首个step立即输出。JSON及SSE done提供phase_timings与llm_reason；每个阶段包含耗时与已返回物理调用耗时。宿主deadline发生时单次完整在途耗时未知，不能虚填0。
