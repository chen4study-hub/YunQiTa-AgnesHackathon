# Deterministic Agent tools

Deterministic physical/context tools live in src/agent/tools.py and are independent of the LLM. Chat adapters live in src/agent/chat_tools.py. src/agent/numeric_prompt.py constructs one-decimal value/meaning/source prompts from rounded evidence; it adds no sources and does not relax grounding validation.

- get_forecast(fetch,building_id,start,end): end-exclusive hourly calls to supplied model fetch function, preserving interval/confidence/rejection/reason; avoids secretly using stale replay data as online predictions.
- get_context(building_id,start,end,replay=None): complete-hour context from existing replay (or explicitly supplied replay), local wall-clock TOU tariff from configs/agent_tools.json, outdoor temperature, current exported snapshot SOC from matching row.storage.soc, PV output. storage_soc_source=replay.storage.soc; storage_soc_basis identifies this snapshot. Do not read previous row or subtract the exported battery command again. This snapshot is the historical exporter’s post-command derived SOC, not a measured beginning-hour meter; new /schedule comparisons initialize from the selected snapshot. Historical exporter/evaluation propagation still initializes each step with its separate prior execution state; not routed through this snapshot adapter. Missing hours/buildings raise an error rather than fabricate context. SOC/PV are replay synthetic data and tariff is a CNY demonstration configuration, not verified Minnesota billing.
- simulate_schedule(plan,forecast,constraints=None,context=None,precool_hours=()): linear scenario via supplied complete hourly context. Positive battery power discharges; unit efficiency, no export credit. Temperature load sensitivity3%/C above24C; precooling adds5% load during specified hours; estimated indoor temperature adds0.02C per outdoor degree above30C. Reports grid energy, cost, peak and degree-hours outside24-27C, hourly SOC, baseline-relative estimated savings. These are unvalidated scenario estimates, not measured or calibrated savings. Refused forecasts passed directly produce null economics. Chat what-if explicitly filters the same accepted hours and matching contexts before both calls; compare_costs reports accepted-only differences plus every excluded local hour/gate reason. All-refused comparison retains null costs; empty plan is not simulated. Without hourly context cost/savings stay null. Endpoint integration does not silently substitute synthetic context for live measurements.
- check_constraints(plan,constraints=None):24-27C setpoints, abs battery<=500kW, sequential SOC10-95% using configured capacity2000kWh; optional constraints may tighten but not relax these hard bounds. Handoff cannot dispatch battery power. Setpoint feasibility does not prove indoor comfort; simulation separately reports indoor degree-hours.
- explain_uncertainty(forecast): refuses causal inventions. Returns only supplied confidence, interval width, risk/threshold and reported refusal reason. Missing trigger evidence is explicitly unknown; accepted hours generate no refusal explanation.

24step replay/export/eval uses storage_planner.optimize_power: a lexicographic LP minimizes upper-grid-peak then24h accepted-step tariff cost then throughput, with valley-only charge/peak-only discharge, refused fixed0, SOC hard10–95%, power500kW and terminalSOC>=initial. Full/conservative/hold maxpower500/250/0; identical paths merged rather than duplicate proposals; selection then merges equal one-decimal displayed (cost,upper peak) pairs, retaining raw peak-first/cost-second/id best of each group, not inventing a new proposal. Accepted current always invokes provider choice; future refusal remains0power, included in Chinese summary with local time and no current handoff. Only current refusal bypasses LLM with refused_current. Setpoint25.5C, no unsupported precooling benefit. Candidates retain full precision for controls; evidence display remains rounded. rolling_context uses current+t+1..t+23 (forecast_24h h24 still displayed, not a25th control step), origin weather persistence/currentPV/futurePV0. Only first command executes, subsequent hourly run replans from propagated executed SOC (export/evaluation); API snapshot SOC remains canonical current row. Public reason prose uses Chinese 千瓦/电量/度 and rejects internal English words. Original shorter/live1step routine remains conservative, not an invented forecast path.

Forecast and schedule hourly timestamps must align. Demonstration defaults are comfort midpoint25.5C, battery max500kW/capacity2000kWh. Existing provider still passes through constraint checks and log-only dispatch; no equipment connection. Tests use deterministic fixtures and do not call the real LLM.
