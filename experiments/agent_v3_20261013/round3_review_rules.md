# 开/关同版本验收规则（运行前冻结）

两边同一源码、数据、问题和断言。91题每题独立session；10组各2问，组内共享session/history/context，整组在同批不重启，批≤5题。先运行on全91和10组，再off同样输入；只有一个本人临时端口/tempDB后端。顺序不是随机交叉A/B，上游负载、联网资料随时间可能变化，不能声称纯开关因果实验。

自动判分：probe.evaluate要求known/grounded、所需工具、放宽后的contains/excludes和数量约束；业主物业明确系统没有、reason=no_data可正确。语义额外查实际pipeline产生的trace，不以预期答案制造证据；v3取实际run_tool records，旧路径取guarded_events最终真实trace并经过相同compact_evidence/display_evidence，不用给旧路径套v3专用record格式而全部误判。新闻、单字段、累计储能、回执、健康诊断按同一semantic_assertions。多轮HVAC排除时刻允许同日省略今天和连续时刻范围，实际全部时刻/原因必须存在。自动失败不在人工复核中升级，收据保留。

人工扣分：逐题/逐轮检查全文及工具证据，只有自动通过题才可能扣分（整题一次，记录具体句子及同规则编号）。
- R1 数值/单位/对象/范围错误：累计与瞬时混淆，电网当总负荷，错楼层/电梯/当前占比，错误数量或健康正常结论；数据没有却断言已查/已执行/无故障。
- R2 关键任务遗漏：答非所问；仅“先查/稍后”或失败提示；未满足用户条目数/两句等明确格式；多轮不能利用前文所问读数、相对温度或排除时刻。
- R3 内部泄露与不当措辞：think标签/内容、工具名/snake_case/JSON、禁止词/策略容差门控区间上界；过渡句当结论。BA/EMS、来源名称、科学单位、URL内部字节不扣。
- R4 新闻/来源错误：标题或实际正文主题不符（关键词偶然匹配不算），新闻过14天、旧事件当今天，链接未查询/编造；无相关新闻却夹带城市天气或其它链接。确实查询但无相关结果的单句“没查到相关报道。”可正确，不因无新闻强扣。
- R5 回执：实际count、elapsed、数字与条/ms/毫秒有空格、BA/EMS下发日志标签；绝不把日志当现场设备完成。
- R6 呈现：读数千分位/最多一位，电价例外两位、单位空格；同日只时间、跨天次日，一句最多两次今天/次日；同一个意思显著重复。时钟、日期、URL、ID不作数字变形扣分；科学PM2.5/CO₂及楼层号不要求一位。

统计：全91逐题自动通过、扣分后通过、模型自己答题数（mode=llm且explanation_source=llm，另列模型通过）、中位、nearest-rank P90、最慢题/耗时、首响应/完整请求超时、模板次数、空答/>25秒。多轮列逐轮20题及全部两轮都过的10组；模型组数也两轮都为模型。上游统计只包括已instrument的AgentProvider或旧provider chat/chat_stream及最终host阶段超时，不含话题分类，区分调用与受影响题，不重复累加host+transport同一调用。不把模板通过冒称模型质量达标。CHAT_AGENT_LOOP继续默认关闭。需要重启。
