4. 评分由原固定contains + 数字/来源/工具校验 + 所问字段实值检查组成。不修改原91 corpus，只生成本次46题派生输入；25条断言改动理由逐条列于末尾。价格仍元/kWh两位，其余一位，默认开关未改变。app.py、主导出、ops/db/规划器/twin均未改。
