# 场景性能收尾（2026-10-13）

## 最终范围

只保留 EChart：相同尺寸切回复用 backing canvas；配置未变不再 setOption；隐藏期间变化的配置在返回后补上，避开尺寸回调里的同步模型工作。实例不重建，resize/数据变化/浮窗仍更新。

BottomBar、Timeline、TwinSceneView、TwinScene、chartPhases 的试验修改全部撤回。BottomBar 原 13–17 行时钟更新保持原样，最终没有提交 BottomBar。未改 store.ts、App.tsx、data/ops、validators、floors 或后端。

## 口径

生产 preview，Edge headless，1366×768@1、1600×900@1.25、1920×1080@1；无 CPU 人为降速，沿用项目关闭帧率限制/GPU vsync 参数。每个尺寸独立上下文三次，场景就绪后等待 2.5 秒；在点击播放之前开始记录 rAF 时间戳，保留开播 600ms 内所有间隔（包含跨越结束边界的最后一个间隔）。太阳实际向量按 100ms 采样 2.2 秒，报告各次最大夹角的中位数。

切回口径是点击 Agent 页的总览按钮到第 2 个 rAF；同时记录当时实际 page/hidden 状态，不能把尚未完成导航的数字当成功切回。

改前使用 22ecfcb 中六个本轮相关源文件的只读构建替换，其他文件取同时工作区；未还原或覆盖他人文件。改后取最终仅 EChart 的版本。共享机器负载、他人同步改动仍会影响测量，以下不是稳定收益保证。
